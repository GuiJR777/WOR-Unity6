# Whiskers of Rage — Unity 6 Base

Base técnica enxuta para acelerar o primeiro vertical slice jogável.

Inclui:
- Unity Input System;
- movimento isométrico XZ;
- pulo matemático, coyote time, jump buffer e altura variável;
- dash e impulsos externos;
- HFSM de locomotion/incapacitação;
- GAS-inspired mínimo;
- HitBox/HurtBox e dano via Ability System;
- combo Light condicionado a hit-confirm;
- Heavy Attack, Block e Parry prototype;
- Poise, Stun, Knockback, Launch, Knockdown e Death;
- Behavior Tree simples para Enemy_Test;
- Quick Start de Editor e documentação.

O objetivo não é criar um framework universal. A base existe para levar WOR rapidamente a um combate testável e crescer somente quando o jogo exigir.

Comece por Docs/QUICKSTART.md.
